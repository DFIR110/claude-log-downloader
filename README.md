# CLAUDE Log Downloader

claude.ai の「設定 → プライバシー → データをエクスポート」で届く manifest を読み、                                         
zip のダウンロードリンクを1つずつ開くためのページです。

## 使い方

1. claude.ai にログインしているブラウザで、このページを開く                                                                
2. manifest(manifest-….json)を選ぶ
3. 表示されたリンクを1つずつ開いて zip を落とす

## 特徴

- 1個の HTML ファイルで動きます。保存して USB から開くこともできます
- manifest はブラウザの中で読むだけで、外部へは送信しません
- 外部のプログラムやフォントを読み込みません

## 注意

- リンクは作成から24時間で使えなくなり、1回しか使えないことがあります                                                      
- Safari の場合、設定の「ダウンロード後、"安全な"ファイルを開く」をオフにしてください
- Anthropic とは関係のない、非公式の道具です
